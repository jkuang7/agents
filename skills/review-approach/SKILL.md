# Review approach

Compare strategies when the choice is consequential, costly or hard to reverse, several credible approaches differ materially, and a cheap experiment cannot settle it. Otherwise recommend direct implementation or the smallest useful tracer bullet.

State the outcome and fixed constraints. Compare only options whose differences could change the decision, using correctness, cognitive load, coupling, testability, reversibility, operational risk, and applicable migration cost. Prefer the simplest supported approach with the lowest total risk.

Use repository behavior and direct evidence. Distinguish facts from judgment and disclose assumptions that affect the recommendation. If a missing fact controls the decision, identify the cheapest experiment to resolve it.

Stop when further analysis is unlikely to change the choice. Return the outcome, credible options, decisive tradeoffs, recommendation, and any needed experiment. Add a formal brief, diagram, or decision record only when it helps people act.
