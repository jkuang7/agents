# Local skills

This directory contains skills authored in this repository.

Each skill lives at `skills/<name>/SKILL.md`. Keep the directory name equal to
the `name` in the skill frontmatter, then run `bin/deploy` from the repository
root to expose it to Codex, Claude Code, and other compatible agents.

Third-party skills do not belong here. Matt Pocock's imported skills live under
`vendor/matt-pocock-skills/` and are deployed into the same runtime catalog.
